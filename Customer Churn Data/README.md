# Customer Churn Analysis

## Overview
This project explores customer churn patterns data to identify the key drivers of attrition and provide actionable recommendations for retention strategies. The analysis focuses on understanding how customer demographics, tenure, and product usage influence churn behaviour.

## Tools & Skills
Power BI (dashboard development and visualization)
Power Query (data cleaning and preprocessing)

## Dataset
Bank customer churn dataset provided by TechyJaunt Launchpad Program. 
It contains customer demographics, tenure, product usage, churn status amongst others

## Process
1. Cleaned and validated raw data to ensure accuracy
2. Built Power BI dashboard to visualize churn trends and customer segments
3. Conducted statistical analysis to highlight high-risk customer groups.
   
## Key Insights
1. Customers with shorter tenure and fewer products showed significant higher churn rates
2. Female customers exhibited slightly higher churn probability compared to male customers
3. Product count and tenure were the strongest predictors of churn

## Recommendation
Target retention campaigns for short-tenure customers and those with limited product engagement.
